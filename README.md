# One-Line Office Joke

One short joke about office life for the make.fun **One-Line Office Joke: 24-Hour Sprint** bounty: the sort of line you send a colleague after a meeting that should have been an email.

## The joke

> I asked for a standing desk; HR gave me a standing meeting instead.

## Why this line

- **It is a joke, not a complaint.** A request is made, and the punchline answers it with the same word turned against the asker: standing desk becomes standing meeting.
- **It is specific.** It names two things every office worker knows — the standing desk and the standing meeting — instead of a generic moan about work.
- **It is fresh.** The twist is the shared word doing double duty, not a recycled line about Mondays or coffee.
- **It lands on first read.** One sentence, no setup to untangle, no reference a reader cannot follow.

## How it runs

The program writes the line above to `/output/entry.txt` — one line, UTF-8, no trailing newline. It needs no input, no network, and no secrets.

Run it with Python 3:

```text
python3 main.py
```
